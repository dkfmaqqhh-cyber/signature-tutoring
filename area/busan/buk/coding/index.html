TEST WITH INPUTS

입력값이 달라지면 틀린다면, 세 가지 값으로 확인합니다

정상 입력

흔히 들어올 값입니다. 예: 점수 75

경계값

조건이 바뀌는 바로 그 값과 앞뒤 값입니다. 예: 60점 기준이면 59·60·61

예상하지 못한 값

범위를 벗어나거나 생각하지 않은 값입니다. 예: 음수 점수

EXPECTED VS ACTUAL

예상 결과와 실제 결과를 비교합니다

목표: 0~100점 중 60점 이상이면 "통과" (직접 만든 설명용 예시, 파이썬 실행 결과)

파이썬 · 조건과 입력값

1. 처음 작성한 코드

def check(score):
    if score > 60:
        return "통과"
    return "재도전"

for s in [75, 60, -5]:
    print(s, check(s))

60 재도전
-5 재도전

2. 수정한 코드와 다시 실행한 결과

def check(score):
    if score < 0 or score > 100:
        return "잘못된 점수"
    if score >= 60:
        return "통과"
    return "재도전"

for s in [75, 60, -5]:
    print(s, check(s))

60 통과
-5 잘못된 점수

북구 코딩과외 자주 묻는 질문

북구에서도 방문 없이 코딩 수업을 받을 수 있나요?
네. 코딩 수업은 방문수업 없이 실시간 1:1 화상으로만 진행합니다. PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 있으면 집에서 수업을 받을 수 있습니다.
문법 문제는 맞히는데 직접 짠 코드는 자주 틀려요.
문법 문제는 정해진 입력 하나로 확인하는 경우가 많지만, 실제 코드는 여러 입력값을 처리해야 합니다. 수업에서는 정상 입력·경계값·예상하지 못한 값을 넣어 예상 결과와 실제 결과를 비교하는 연습을 합니다.
경계값은 어떻게 찾나요?
조건에 쓰인 기준 값과 그 바로 앞뒤 값을 넣어 봅니다. 예를 들어 60점 이상을 통과로 정했다면 59, 60, 61을 넣어 결과를 확인합니다.
수정 기록은 어떻게 남기나요?
틀린 입력값, 예상 결과와 실제 결과, 원인, 고친 내용을 한 줄씩 적습니다. 다음 수업과 녹화 복습 때 이 기록을 함께 보며 같은 실수를 다시 확인합니다.
수업료와 무료 체험은 어떻게 되나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 시간과 과정은 상담 후 정하며, 구성 변경에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업이 가능합니다.
