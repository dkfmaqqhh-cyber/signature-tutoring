FROM COPYING TO WRITING

예제는 따라 쓰는데 혼자 작성하기 어렵다면

따라 쓰기는 이미 정해진 답을 옮기는 연습이고, 직접 작성은 무엇을 만들지부터 정하는 연습입니다.

1. 말로 정리하기

만들 프로그램이 무엇을 받아서 무엇을 보여 주는지 한두 문장으로 먼저 말해 봅니다.

2. 부분으로 나누기

입력·처리·출력으로 나눠 각 부분에 필요한 코드가 무엇인지 정합니다.

3. 한 부분씩 실행하기

한 번에 다 쓰지 않고 한 부분을 작성할 때마다 실행해 결과를 확인합니다.

INPUT · PROCESS · OUTPUT

작은 프로그램을 입력·처리·출력으로 나눠 봅니다

예시: 물건 가격과 개수를 입력받아 합계를 보여 주는 프로그램 (직접 만든 설명용 예시)

부분하는 일이 예시에서
입력사용자에게 값을 받기가격과 개수를 입력받음
처리받은 값으로 계산하기가격 × 개수를 계산
출력결과를 보여 주기"합계: …"를 화면에 출력
READING ERRORS

오류 메시지를 읽고 고치는 연습

위 예시를 파이썬으로 작성해 실행한 결과입니다. 가격에 1200, 개수에 3을 입력했습니다.

파이썬 · 입력과 자료형

1. 처음 작성한 코드

price = input("가격: ")
count = input("개수: ")
total = price * count
print("합계:", total)

2. 실행하면 오류가 납니다 (오류 메시지 마지막 줄, 파이썬 3.12 기준)

TypeError: can't multiply sequence by non-int of type 'str'

TypeError는 값의 종류(자료형)가 맞지 않을 때 나는 오류입니다. input()으로 받은 값은 숫자처럼 보여도 문자열이라, 문자열끼리는 곱할 수 없다는 뜻입니다.

3. 숫자로 바꿔 다시 실행합니다

price = int(input("가격: "))
count = int(input("개수: "))
total = price * count
print("합계:", total)
합계: 3600

수업에서는 이렇게 오류 메시지를 함께 읽고, 학생이 원인을 직접 말해 본 뒤 고치는 순서로 연습합니다.

FAQ

동래구 코딩과외 자주 묻는 질문

동래구에서도 방문 없이 코딩 수업을 받을 수 있나요?
네. 코딩 수업은 방문 없이 실시간 1:1 화상으로만 진행합니다. PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 있으면 집에서 수업을 받을 수 있습니다.
예제는 따라 하는데 혼자서는 코드를 못 쓰겠어요.
따라 쓰기와 직접 작성하기는 다른 연습이 필요합니다. 수업에서는 만들 프로그램을 말로 정리하고 입력·처리·출력으로 나눈 뒤, 한 부분씩 직접 작성해 실행해 보는 연습을 합니다.
오류 메시지가 나오면 어떻게 공부하나요?
오류 메시지의 마지막 줄에서 오류 종류와 내용을 먼저 읽고, 어느 줄에서 났는지 확인합니다. 원인을 말로 설명해 본 뒤 고쳐서 다시 실행하는 순서로 연습합니다.
학교 수업 준비와 방학 기초 학습은 무엇이 다른가요?
학교 수업 준비는 학생의 교재·배우는 언어·진도·평가 범위를 기준으로 계획하고, 방학 기초 학습은 목표와 가능한 시간에 맞춰 기본 개념과 실습을 집중적으로 익힙니다. 실제 계획은 상담에서 확인해 정합니다.
수업료와 무료 체험은 어떻게 되나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 시간과 과정은 상담 후 정하며, 구성 변경에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업이 가능합니다.
