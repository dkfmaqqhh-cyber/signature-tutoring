BEFORE CONSULTING

상담 전에 확인해 두면 좋은 것

  • 처음 배운다면 — 학년, 컴퓨터로 타자를 치거나 프로그램을 설치해 본 경험, 코딩을 배우려는 이유를 알려 주세요.
  • 학교 수업 준비라면 — 학교에서 받은 교재나 수업 자료, 배우는 언어와 단원, 평가 범위를 확인해 주세요. 학교마다 교육과정과 평가 범위가 다르므로 학생의 자료를 기준으로 계획합니다.
  • 배운 경험이 있다면 — 배운 언어·도구와 단원, 혼자 작성해 본 코드, 어려웠던 부분을 상담 때 알려 주세요.
  • 성인·직장인이라면 — 사용해 본 언어·도구와 배우려는 목적, 어려운 부분을 알려 주세요.
  • 공통 — 수업 가능한 요일·시간과 PC 또는 노트북 사용 가능 여부를 확인해 주세요.

2. 실행하면 오류가 납니다 (오류 메시지 마지막 줄, 파이썬 3.12 기준)

NameError: name 'score' is not defined. Did you mean: 'scores'?

오류 메시지는 score라는 이름을 찾을 수 없다고 알려 주고, 비슷한 이름 scores를 제안합니다. 위에서 만든 리스트 이름은 scores인데, 마지막 줄에서 s를 빠뜨리고 썼기 때문입니다.

3. 이름을 고쳐 다시 실행합니다

print("평균:", total / len(scores))
평균: 81.66666666666667

수업에서는 이렇게 오류 메시지를 함께 읽고, 학생이 원인을 직접 말해 본 뒤 고치는 순서로 연습합니다. 자바를 배우는 경우에도 같은 방식으로 작성·실행·오류 확인을 반복합니다.

고친 코드는 수업 녹화로 다시 보고, 다음 수업에서 비슷한 코드를 보지 않고 작성해 같은 오류 없이 실행되는지 확인합니다.

FAQ

금정구 코딩과외 자주 묻는 질문

금정구에서도 방문 없이 코딩 수업을 받을 수 있나요?
네. 코딩 수업은 방문 없이 실시간 1:1 화상으로만 진행합니다. PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 있으면 집에서 수업을 받을 수 있습니다.
상담 전에 무엇을 확인해 두면 좋나요?
학년과 배우려는 목적, 지금까지 배운 언어나 경험, 학교 수업이 목적이라면 교재와 평가 범위, 수업 가능한 요일·시간을 알려 주시면 시작 단계를 정하는 데 도움이 됩니다.
방학 수업과 학기 중 수업은 어떻게 다른가요?
방학에는 기본 개념과 실습을 집중적으로 익히고, 학기 중에는 학교 정보·코딩 수업에서 배우는 내용을 이해하도록 준비합니다. 실제 계획은 학생의 학교·학년·언어·평가 범위를 상담에서 확인해 정합니다.
수업 내용을 다시 볼 수 있나요?
네. 수업 녹화 기능을 활용해 수업 후 다시 보며 복습할 수 있습니다.
수업료와 무료 체험은 어떻게 되나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 시간과 과정은 상담 후 정하며, 구성 변경에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업이 가능합니다.
