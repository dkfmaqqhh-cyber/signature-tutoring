파이썬 · 들여쓰기

1. 1부터 5까지 중 짝수만 더하려고 작성한 코드

total = 0
for n in range(1, 6):
    if n % 2 == 0:
    total = total + n
print("짝수의 합:", total)

2. 실행하면 오류가 납니다 (오류 메시지 마지막 줄, 파이썬 3.12 기준)

IndentationError: expected an indented block after 'if' statement on line 3

3번째 줄 if 다음에 실행할 코드가 들여쓰기되어 있지 않다는 뜻입니다. 블록코딩에서 조건 블록 안에 블록을 넣던 것을, 파이썬에서는 들여쓰기로 표시합니다.

3. 4번째 줄을 한 단계 더 들여 써서 다시 실행합니다

total = 0
for n in range(1, 6):
    if n % 2 == 0:
        total = total + n
print("짝수의 합:", total)

FAQ

해운대구 코딩과외 자주 묻는 질문

해운대구에서도 방문 없이 코딩 수업을 받을 수 있나요?
네. 코딩 수업은 방문수업 없이 실시간 1:1 화상으로만 진행합니다. PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 있으면 집에서 수업을 받을 수 있습니다.
블록코딩만 해 봤는데 파이썬이나 자바를 시작할 수 있나요?
네. 블록코딩에서 익힌 순서·반복·조건의 생각은 그대로 이어집니다. 다만 텍스트 코딩은 명령을 직접 입력하고 파이썬은 들여쓰기, 자바는 중괄호로 코드를 묶으므로 이 차이부터 연습합니다. 시작 언어는 목적과 현재 수준을 상담에서 확인해 정합니다.
변수·조건·반복은 아는데 직접 코드를 못 쓰겠어요.
설명할 수 있는 것과 직접 작성하는 것은 다른 연습이 필요합니다. 수업에서는 점수에 10점 더하기, 60점 이상이면 통과 출력하기처럼 작은 과제를 직접 작성해 실행해 보는 연습을 반복합니다.
녹화된 수업은 어떻게 복습에 쓰나요?
수업에서 오류를 고친 부분을 다시 보고, 다음 수업 전에 같은 코드를 보지 않고 다시 작성해 보는 데 활용할 수 있습니다. 다시 봐도 이해되지 않는 부분은 표시해 두었다가 다음 수업에서 질문하면 됩니다.
수업료와 무료 체험은 어떻게 되나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 시간과 과정은 상담 후 정하며, 구성 변경에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업이 가능합니다.
