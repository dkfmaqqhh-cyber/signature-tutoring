EXPLAIN YOUR CODE

코드는 동작하는데 왜 그렇게 작성했는지 설명하기 어렵다면?

짧은 답 코드 전체를 처음부터 한 줄씩 읽어 내려가기보다, 프로그램이 만들려는 결과와 각 부분이 맡은 역할을 이어서 설명해 봅니다. 그다음 한 부분을 바꿨을 때 동작이 어떻게 달라질지 먼저 말로 예상하고, 실행 결과와 비교하며 설명을 다시 다듬습니다.

지역과 관계없이 쓰는 일반적인 학습 방법입니다. 아래 예시는 「목록 [40, 70, 90]에서 60 이상인 값의 개수를 세는 짧은 프로그램」을 설명해 보는 개념 설명용 상황이며, 특정 도구나 실제 학생 사례가 아닙니다. 예시의 숫자는 손으로 계산해 확인할 수 있는 값입니다.

  1. 프로그램이 하려는 일을 한 문장으로 설명

    직접 해 볼 것 코드를 보기 전에 「이 프로그램은 ○○을 확인해서 △△을 보여 준다」는 형태로 한 문장을 적습니다.

    예 「목록의 점수 가운데 60 이상인 것이 몇 개인지 세어 보여 준다」

    확인 질문 이 문장만 듣고 다른 사람이 어떤 결과가 나올지 알 수 있나요?

  2. 입력·처리·결과에 해당하는 부분 구분

    직접 해 볼 것 코드에서 입력, 처리, 결과에 해당하는 줄에 서로 다른 표시를 합니다.

    예 입력 — [40, 70, 90]을 담는 부분 / 처리 — 값을 하나씩 꺼내 60 이상인지 확인하고 세는 부분 / 결과 — 센 개수를 보여 주는 부분

    확인 질문 어느 표시에도 넣지 못한 줄이 있다면, 그 줄은 무엇을 하나요?

  3. 변수·조건·반복 중 사용한 개념의 역할 설명

    직접 해 볼 것 사용한 개념마다 「무엇을 하는가」보다 「왜 필요한가」를 한 문장씩 적습니다.

    예 반복 — 값 세 개를 하나씩 보기 위해 / 조건 — 지금 보는 값이 60 이상인지 확인하기 위해 / 개수를 기억하는 값 — 지금까지 센 수를 남겨 두기 위해. 0에서 시작해 40을 볼 때 0, 70에서 1, 90에서 2가 됩니다.

    확인 질문 개수를 기억하는 값이 없다면 마지막에 무엇을 보여 줄 수 있을까요?

  4. 한 부분을 바꾸면 어떤 동작이 달라질지 예상

    직접 해 볼 것 한 부분만 바꾼다고 정하고, 실행하기 전에 바뀐 결과와 그 이유를 먼저 적습니다.

    예 기준을 80으로 바꾸면 90만 해당해 1개 / 기준은 60 그대로 두고 목록에 60을 더하면 「60 이상」이므로 60도 포함돼 3개

    확인 질문 바꾼 부분은 입력·처리·결과 가운데 어디에 속하나요?

  5. 설명과 실행 확인을 비교하고 다시 정리

    직접 해 볼 것 적어 둔 대로 직접 바꿔 실행하고 예상과 비교합니다. 다르면 처음 설명 가운데 어느 문장이 틀렸는지 찾아 고쳐 적습니다.

    예 예상과 달랐다면 조건의 기준값과 「이상」·「초과」의 차이를 다시 확인하고, 2단계·3단계의 설명을 고쳐 쓰기

    확인 질문 처음 설명에서 고친 문장은 무엇이고, 왜 고쳤나요?

자기 말로 설명할 때는 「이 줄이 무엇을 하는가」보다 「왜 필요한가」와 「바꾸면 어떻게 되는가」에 답할 수 있는지를 기준으로 확인합니다. 파이썬·자바 모두 같은 방식으로 연습할 수 있으며, 실제 연습 코드는 배우는 언어와 수준에 맞춰 정합니다.

FAQ

충남 코딩과외 자주 묻는 질문

코딩을 처음 배우는데 시작할 수 있나요?
네. 처음이라면 써 본 도구가 있는지부터 확인하고, 결과가 바로 보이는 짧은 코드를 직접 작성·실행하며 코딩 기초를 시작합니다. 짧은 코드라도 무엇을 하려고 쓴 것인지 말로 설명해 보면서 진행하며, 학교 수업을 보완하려면 사용하는 언어·도구와 교재·단원·평가 범위를 알려 주세요.
코드가 동작해도 설명하기 어렵다면 어떻게 배우나요?
먼저 프로그램이 하려는 일을 한 문장으로 말하고, 입력·처리·결과에 해당하는 부분을 나눈 뒤 사용한 변수·조건·반복이 각각 왜 필요한지 설명해 봅니다. 이어서 기준값처럼 한 부분을 바꾸면 결과가 어떻게 달라질지 먼저 예상하고, 실행 결과와 비교해 설명을 다시 정리합니다.
앱·게임 제작과 파이썬·자바 중 무엇부터 배우나요?
직접 만든 동작을 화면에서 확인하며 게임 만들기를 경험하고 싶다면 앱·게임 제작, 짧은 코드로 파이썬 기초를 익히려면 파이썬, 자바 문법과 실행 순서·오류 메시지부터 익히려면 자바 안내를 살펴보세요. 시작 과정은 사용해 본 도구와 배우려는 목적을 상담에서 확인해 정합니다.
충남에서 방문수업도 가능한가요?
코딩 수업은 방문수업 없이 화상으로만 진행합니다. 약속한 시간에 선생님과 실시간 1:1로 만나며, PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 필요합니다. 과정별 프로그램과 설치 방법은 상담에서 안내합니다.
성인·직장인이나 독학 중인 사람도 상담할 수 있나요?
네. 성인·직장인은 코딩 경험과 배우려는 목표, 어려운 부분, 수업 가능한 요일·시간을 기준으로 상담합니다. 독학 중이라면 따라 해 본 예제와 직접 작성한 코드, 설명하기 어려웠던 부분을 알려 주시면 이어서 배울 범위를 함께 정합니다.
수업료와 무료 체험은 어떻게 확인하나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 구성은 상담 후 정하며, 구성에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업은 상담 신청 후 선생님 일정을 확인해 진행 방법을 안내합니다.
