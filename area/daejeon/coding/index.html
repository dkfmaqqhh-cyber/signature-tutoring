TEST WITH MANY INPUTS

한 번 실행된 코드를 다른 입력에서도 확인하려면 어떻게 하나요?

짧은 답 예상 결과를 먼저 적고, 일반적인 값과 경계에 해당하는 값을 바꿔 실행하며 조건과 계산 과정을 확인합니다.

지역과 관계없이 수업에서 쓰는 일반적인 학습 방법입니다. 아래 예시는 「점수가 60점 이상이면 통과」라는 조건을 설명용으로 든 활동이며, 코드 없이 예상 결과를 적어 보는 것부터 시작할 수 있습니다.

  1. 프로그램이 받아야 할 입력과 예상 결과 정리

    어떤 값을 입력받고, 값에 따라 어떤 결과가 나와야 하는지 먼저 적어 둡니다.

    예 입력: 0~100 사이 점수 하나 / 결과: 60 이상이면 「통과」, 60 미만이면 「통과 아님」

  2. 평소 사용하는 입력으로 기본 동작 확인

    기준에서 충분히 떨어진 보통의 값으로 두 가지 결과가 각각 나오는지 확인합니다.

    예 85점은 「통과」, 30점은 「통과 아님」으로 예상

  3. 조건이 바뀌는 경계의 앞·같음·뒤 확인

    결과가 바뀌는 기준값과 그 바로 앞·뒤 값을 넣기 전에 예상 결과를 적고, 실행한 결과와 비교합니다.

    예 59점은 「통과 아님」, 60점은 「이상」이므로 「통과」, 61점은 「통과」로 예상

  4. 예상과 다른 경우 관련 조건·계산을 하나씩 확인

    다른 결과가 나온 입력에서 그 결과를 만든 조건문과 계산을 한 곳씩 살펴보고, 한 번에 한 곳만 고칩니다.

    예 만약 60점에서 「통과 아님」이 나온다면, 조건이 「60 이상」이 아니라 「60 초과」로 쓰였는지 확인

  5. 수정 후 앞서 확인한 입력도 다시 점검

    고친 부분이 다른 입력의 결과를 바꾸지 않았는지, 앞에서 확인한 값을 모두 다시 넣어 봅니다.

    예 59·60·61점뿐 아니라 85점과 30점도 다시 확인

파이썬·자바 모두 같은 순서로 연습하며, 실제 연습 문제는 배우는 언어와 범위에 맞춰 정합니다. 어떤 값을 확인해야 할지 정하기 어려운 부분은 수업 중에 함께 정합니다.

대전 코딩과외 자주 묻는 질문

코딩을 처음 배우는데 시작할 수 있나요?
네. 사용해 본 도구와 경험을 먼저 확인하고, 결과를 바로 볼 수 있는 짧은 코드부터 직접 작성하고 실행하며 시작합니다. 학교 정보·프로그래밍 수업을 보완하려는 경우에는 사용하는 언어와 교재·단원·평가 범위를 상담에서 확인해 계획합니다.
한 번 실행된 코드는 어떻게 복습하나요?
한 번 실행된 것으로 끝내지 않고, 예상 결과를 먼저 적은 뒤 평소 쓰는 값과 조건이 바뀌는 경계의 앞·같음·뒤 값을 넣어 다시 실행해 봅니다. 예상과 다른 결과가 나오면 관련 조건과 계산을 하나씩 확인해 고치고, 고친 뒤에는 앞서 확인한 입력도 다시 점검합니다. 수업 녹화로 확인 과정을 다시 볼 수 있습니다.
앱·게임 제작과 파이썬·자바 중 무엇부터 배우나요?
실행 결과를 화면에서 바로 보며 움직임과 상황을 구성해 보고 싶다면 앱·게임 제작, 기초 문법에서 데이터 분석·자료구조까지 이어 가고 싶다면 파이썬, 기초 문법을 익히며 짧은 코드를 작성·실행하고 오류를 확인해 보려면 자바 안내를 먼저 살펴보세요. 사용해 본 도구와 배우려는 목적을 상담에서 확인해 시작 과정을 정합니다.
대전에서 방문수업도 가능한가요?
코딩 수업은 방문수업 없이 화상으로만 진행합니다. 정해진 시간에 선생님과 실시간 1:1로 만나며, PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 필요합니다. 과정별로 필요한 프로그램과 설치 방법은 상담에서 안내합니다.
성인·직장인도 상담할 수 있나요?
네. 사용해 본 언어와 도구, 현재 이해하는 내용과 어려운 부분, 배우려는 목적과 희망 범위, 수업 가능한 요일과 시간을 알려 주시면 학습 범위를 정하고 선생님 일정을 확인해 안내합니다.
수업료와 무료 체험은 어떻게 확인하나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수강 범위와 수업 구성은 상담 후 정하며, 구성에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업은 상담 신청 후 선생님 일정을 확인해 진행 방법을 안내합니다.
