학습 상황에 맞는 시작점

처음 배우는지, 학교 수업을 보완하려는지, 혼자 쓰다 막혔는데 무엇을 어떻게 물어야 할지 모르는지에 따라 첫 수업에서 확인할 내용이 달라집니다.

처음 코딩을 배우는 경우

써 본 도구가 있는지 확인하고, 결과가 바로 보이는 짧은 코드를 직접 작성·실행하며 코딩 배우기를 시작합니다. 막히면 그 자리에서 화면을 함께 보며 묻는 방법도 첫 수업에서 익힙니다.

학교 정보·프로그래밍 수업 보완

학교에서 쓰는 언어·도구와 교재·단원·평가 범위를 상담에서 확인하고, 학교 수업에서 막혔던 코드를 화면에 띄워 원인을 함께 확인한 뒤 직접 다시 작성해 봅니다.

혼자 쓰다 막혔지만 무엇을 보여 주고 물어야 할지 모르는 경우

학교마다 교육과정 편성과 사용하는 도구·언어가 다르므로, 실제 교재와 수업 자료를 확인해 안내합니다.

ASK ON SCREEN

화상 코딩수업에서 막힌 부분을 어떻게 보여 주고 질문하나요?

짧은 답 만들려는 결과와 지금 나온 결과를 한 문장씩 말한 뒤, 오류 메시지나 관련된 코드 줄이 보이도록 화면을 준비해 보여 줍니다. 이때 수업과 관계없는 창이나 개인정보는 닫거나 지우고 필요한 부분만 보여 주며, 설명을 들은 뒤에는 학생이 직접 고쳐 실행해 확인합니다.

지역과 관계없이 쓰는 일반적인 학습 방법입니다. 아래 예시는 「점수 세 개의 평균을 보여 주려 했는데 합계가 나왔다」는 가상의 학습 상황이며, 수업에서 쓰는 화상 도구로 화면을 함께 보는 방법은 상담과 첫 수업에서 안내합니다.

  1. 만들려는 결과와 현재 상태를 짧게 설명

    직접 해 볼 것 질문하기 전에 「무엇을 만들려고 했는지」와 「지금 어떻게 나오는지」를 한 문장씩 정리합니다.

    예 「점수 80, 90, 70의 평균 80을 보여 주려 했는데, 240이 나온다」

    확인 질문 기대한 결과와 지금 나온 결과를 각각 한 문장으로 말할 수 있나요?

  2. 오류 메시지와 관련 코드 위치 확인

    직접 해 볼 것 오류 메시지가 있으면 가리키는 줄 번호를, 오류 없이 결과만 다르면 그 결과를 만드는 줄을 찾아 화면에 바로 보이게 열어 둡니다.

    예 오류 메시지는 없으므로, 평균을 계산하는 줄과 결과를 보여 주는 줄이 함께 보이도록 화면을 맞춰 두기

    확인 질문 화면에 띄운 부분이 지금 문제와 관련된 줄인가요?

  3. 개인정보를 제외하고 필요한 부분만 공유

    직접 해 볼 것 화면을 보여 주기 전에 메신저·메일·다른 문서 창을 닫고, 코드 편집기와 실행 결과만 남깁니다. 코드나 입력값에 실제 이름·연락처·계정 정보가 들어 있다면 예시 값으로 바꿉니다.

    예 실제 계정 아이디 대신 「test」, 실제 이름 대신 「학생1」처럼 바꿔 두기

    확인 질문 지금 화면에 수업과 관계없는 정보나 개인정보가 보이지 않나요?

  4. 설명을 들은 뒤 직접 수정·실행

    직접 해 볼 것 선생님의 설명을 듣고 원인을 학생이 직접 말해 본 뒤, 학생이 직접 고쳐 실행합니다. 선생님이 대신 고쳐 주지 않습니다.

    예 「합계를 값의 개수 3으로 나누는 부분이 빠져 있었다」면 학생이 그 부분을 직접 써서 실행하고, 240 ÷ 3 = 80이 나오는지 확인하기

    확인 질문 무엇을 왜 고쳤는지 직접 말로 설명할 수 있나요?

  5. 다음에 혼자 확인할 항목 정리

    직접 해 볼 것 오늘 막힌 원인을 바탕으로, 비슷한 상황에서 질문하기 전에 먼저 확인할 것을 한두 줄로 적습니다.

    예 「평균이 이상하면 나누는 부분이 있는지, 나누는 수가 값의 개수와 같은지 먼저 확인」

    확인 질문 같은 문제가 또 생기면 무엇부터 확인하나요?

질문의 목적은 답을 받아 가는 것이 아니라 학생이 원인을 이해하고 직접 고치는 데 있습니다. 「기대한 결과·지금 결과·관련 줄」 세 가지를 짧게 준비해 오면 수업 시간 안에 확인할 범위가 좁혀지고, 화면에는 수업에 필요한 부분만 보여 주면 됩니다.

광주 코딩과외 자주 묻는 질문

코딩을 처음 배우는데 시작할 수 있나요?
네. 써 본 도구가 있는지 먼저 확인하고, 화면에 결과가 바로 보이는 짧은 코드를 직접 작성·실행하며 코딩 기초부터 시작합니다. 막힌 부분은 화면을 함께 보며 바로 질문할 수 있으며, 학교 수업을 보완하려면 사용하는 언어·도구와 교재·단원·평가 범위를 알려 주세요.
화상수업에서 막힌 부분은 어떻게 보여 주고 질문하나요?
만들려는 결과와 지금 나온 결과를 한 문장씩 정리하고, 오류 메시지나 관련 코드 줄이 보이도록 화면을 준비합니다. 수업과 관계없는 창과 개인정보는 닫거나 예시 값으로 바꾸고 필요한 부분만 보여 주며, 설명을 들은 뒤에는 학생이 직접 고쳐 실행해 확인합니다.
앱·게임 제작과 파이썬·자바 중 무엇부터 배우나요?
작은 기능을 직접 만들어 화면에서 움직이는 결과를 보며 게임 만들기를 경험하고 싶다면 앱·게임 제작, 짧은 코드로 파이썬 기초를 익히려면 파이썬, 자바 문법과 실행 순서·오류 메시지부터 익히려면 자바 안내를 살펴보세요. 시작 과정은 사용해 본 도구와 배우려는 목적을 상담에서 확인해 정합니다.
광주에서 방문수업도 가능한가요?
코딩 수업은 방문수업 없이 화상으로만 진행합니다. 정해진 시간에 선생님과 실시간 1:1로 만나며, PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 필요합니다. 과정별로 필요한 프로그램과 설치 방법은 상담에서 안내합니다.
성인·직장인이나 독학 중인 사람도 상담할 수 있나요?
네. 성인·직장인은 코딩 경험과 배우려는 목표, 어려운 부분, 수업 가능한 요일·시간을 기준으로 상담합니다. 독학 중이라면 막힌 코드와 오류 메시지, 무엇을 만들려고 했는지를 알려 주시면 이어서 배울 범위를 함께 정합니다.
수업료와 무료 체험은 어떻게 확인하나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 구성은 상담 후 정하며, 구성에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업은 상담 신청 후 선생님 일정을 확인해 진행 방법을 안내합니다.
