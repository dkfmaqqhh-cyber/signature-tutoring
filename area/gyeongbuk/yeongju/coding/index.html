신호등처럼 정해진 순서로 상태가 바뀌는 프로그램은 어떻게 만드나요?

짧은 답 상태를 순서대로 목록에 담고, 지금 상태의 번호를 1씩 늘리되 끝을 넘으면 0으로 돌아가게 합니다. 바뀌는 차례를 표로 먼저 적고, 마지막 상태 다음에 첫 상태가 나오는지 확인합니다.

STEP 1

처음 확인할 내용

  • 상태 이름을 목록에 순서대로 담을 수 있는지
  • 번호를 1씩 늘리는 반복을 쓸 수 있는지
  • 마지막 번호 다음에 0으로 돌아가는 방법(조건이나 나머지)을 알고 있는지
STEP 2

수업에서 직접 해 볼 연습

  1. 상태를 초록(0)·노랑(1)·빨강(2)으로 정하고, 일곱 번 보여 줄 차례를 표에 적습니다. 초록 → 노랑 → 빨강 → 초록 → 노랑 → 빨강 → 초록입니다.
  2. 번호를 1씩 늘리고 3이 되면 0으로 돌아가게 작성해, 일곱 번 출력한 결과가 표와 같은지 비교합니다.
  3. 같은 동작을 「(번호 + 1)을 3으로 나눈 나머지」로도 써 보고, 두 방법의 결과가 같은지 확인합니다.
STEP 3

복습과 다음 수업에서 확인할 것

  • 상태가 하나 더 늘면 고칠 곳이 어디인지 표시해 둡니다.
  • 상태마다 머무는 시간이 다르면 어떻게 할지 질문으로 적습니다.
  • 다음 수업에서는 버튼을 누를 때마다 다음 상태로 바뀌는 화면으로 이어 갑니다.

위 예시는 설명을 위한 것으로, 지역과 관계없이 같은 질문을 가진 학습자에게 적용하는 일반적인 연습 방법입니다. 실제 연습 내용은 배우는 언어와 수준에 맞춰 정합니다.

  • 정해진 시간에 1:1로 만납니다. 선생님과 같은 시간에 화면으로 만나 수업하며, 방문수업은 진행하지 않습니다.
  • 직접 작성하고 실행합니다. 학생이 코드를 직접 작성·실행하고, 예상과 다른 결과나 오류는 함께 확인하며 바로 질문합니다. 과제를 대신 만들어 주지 않으며, 학생이 스스로 작성하고 이해하도록 돕습니다.
  • 준비물과 복습 PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 필요합니다. 과정별 프로그램과 설치 방법은 상담에서 안내하며, 수업 녹화로 다시 보며 복습할 수 있습니다.

신호등처럼 정해진 순서로 상태가 바뀌는 프로그램은 어떻게 만드나요?
상태를 순서대로 목록에 담고 지금 번호를 1씩 늘리되, 끝을 넘으면 0으로 돌아가게 합니다. 초록·노랑·빨강이라면 일곱 번 바뀐 순서가 표와 같은지 확인하고, 나머지를 쓰는 방법과도 결과를 비교합니다.
앱·게임을 만들고 싶으면 언어 기초부터 따로 배워야 하나요?
꼭 언어 기초부터 따로 시작해야 하는 것은 아닙니다. 앱·게임 제작은 직접 만들어 보는 활동 중심 과정이며, 사용해 본 도구와 경험, 만들고 싶은 것을 상담에서 확인해 앱·게임 제작으로 시작할지 파이썬·자바 기초부터 시작할지 정합니다. 사용할 도구도 상담에서 안내합니다.
영주시에서도 방문수업이 가능한가요?
코딩 수업은 방문수업 없이 실시간 1:1 화상으로만 진행합니다. PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 필요하며, 과정별로 필요한 프로그램과 설치 방법은 상담에서 안내합니다.
학교 정보·프로그래밍 수업 준비도 할 수 있나요?
네. 학교마다 교육과정 편성과 사용하는 도구·언어가 다르므로, 실제 교재·단원·평가 범위와 어려운 코드를 확인해 개념 이해와 직접 작성하는 연습을 연결합니다. 성인·직장인도 학습 목적과 경험을 확인해 상담할 수 있습니다.
수업료와 무료 체험은 어떻게 되나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 시간과 과정은 상담 후 정하며, 구성 변경에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업이 가능하며, 선생님 일정을 확인해 진행 방법을 안내합니다.
