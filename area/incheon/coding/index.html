FROM EXAMPLE TO NEW PROBLEM

예제는 따라 했는데 새로운 문제는 어떻게 시작하나요?

처음 보는 문제를 받았을 때 바로 코드를 쓰기 전에 거치는 시작 순서입니다. 인천만의 방법이 아니라 지역과 관계없이 수업에서 쓰는 일반적인 연습 방법이며, 예시는 「점수 세 개를 입력받아 평균을 구하고, 평균이 60점 이상이면 통과라고 알려 주는 문제」를 설명용으로 든 것입니다. 설치 없이 종이에 적어 보며 따라 할 수 있습니다.

  1. 문제에서 입력·처리·결과 구분하기

    문제 문장을 읽고 무엇을 받는지(입력), 무엇을 계산하거나 판단하는지(처리), 무엇을 보여 주는지(결과)를 세 줄로 나눠 적습니다.

    예 입력: 점수 세 개 / 처리: 합계와 평균 계산, 60점과 비교 / 결과: 평균과 통과 여부

  2. 알고 있는 개념과 처음 보는 조건 나누기

    이미 배운 개념으로 해결할 수 있는 부분과 처음 보는 조건을 따로 표시합니다. 처음 보는 부분은 수업에서 질문하거나 찾아볼 항목으로 남겨 둡니다.

    예 아는 것: 입력 받기, 더하기, 조건문 / 처음 보는 것: 평균이 소수로 나올 때 어떻게 보여 줄지

  3. 해결 순서를 일상적인 문장으로 적기

    코드 문법을 생각하기 전에, 사람에게 설명하듯 해결 순서를 짧은 문장으로 적습니다. 이 문장이 그대로 코드의 순서가 됩니다.

    예 점수 세 개를 받는다 → 모두 더한다 → 3으로 나눈다 → 60 이상인지 비교한다 → 결과를 알려 준다

  4. 기능 하나씩 코드로 옮기고 실행하기

    적어 둔 문장 한 줄을 코드로 옮길 때마다 실행해 중간 결과를 확인합니다. 전부 쓴 뒤 한 번에 실행하지 않습니다.

    예 70, 80, 90을 넣어 합계 240이 나오는지 먼저 확인 → 평균 80 확인 → 마지막에 통과 판단 추가

  5. 조건이나 입력을 바꿔 다시 확인하기

    처음 넣은 값 말고 다른 입력과 경계가 되는 값으로 다시 실행해, 모든 경우에 결과가 맞는지 점검합니다. 복습 때는 기준 점수나 점수 개수를 바꾼 문제로 같은 순서를 반복합니다.

    예 50, 60, 55는 평균 55로 통과가 아니어야 하고, 60, 60, 60은 평균이 딱 60이므로 「60 이상」 조건에 따라 통과로 나와야 한다

파이썬·자바 모두 같은 순서로 연습하며, 실제 연습 문제는 배우는 언어와 범위에 맞춰 정합니다. 어느 단계에서 막히는지 수업 중에 함께 확인하고, 그 단계를 다음 연습의 출발점으로 삼습니다.

FAQ

인천 코딩과외 자주 묻는 질문

예제는 따라 할 수 있는데 새로운 문제는 어디서부터 시작하나요?
먼저 문제에서 입력·처리·결과를 나누고, 이미 아는 개념과 처음 보는 조건을 구분합니다. 해결 순서를 평소 말투의 문장으로 적은 뒤 기능 하나씩 코드로 옮겨 실행하고, 마지막에 입력이나 조건을 바꿔 다시 확인합니다. 수업에서는 이 순서를 학생이 직접 해 보고 막히는 단계에서 질문합니다.
앱·게임 제작, 파이썬, 자바 중 어떤 과정이 맞을지 모르겠어요.
실행 결과를 화면에서 바로 보며 움직임과 상황을 구성해 보고 싶다면 앱·게임 제작, 기초 문법에서 데이터 분석·자료구조까지 이어 가고 싶다면 파이썬, 짧은 코드를 실행하며 기본 문법과 오류 확인부터 익히려면 자바 안내를 먼저 살펴보세요. 사용해 본 도구와 만들고 싶은 결과를 알려 주시면 시작 과정을 함께 정합니다.
코딩이 처음이거나 학교 수업 내용을 보완하고 싶어도 되나요?
네. 처음이라면 경험과 사용해 본 도구를 확인하고 결과를 바로 볼 수 있는 짧은 코드부터 직접 작성합니다. 학교 수업 보완은 학교마다 교육과정 편성과 사용하는 도구·언어가 다르므로, 실제 교재·단원·평가 범위를 상담에서 확인한 뒤 계획합니다.
성인·직장인도 상담할 수 있나요?
네. 코딩을 처음 시작하거나 자바·파이썬을 다시 정리하려는 성인·직장인도 실시간 1:1 온라인수업을 상담할 수 있습니다. 사용하는 언어, 배우려는 목적, 어려운 부분, 수업 가능한 요일·시간을 알려 주시면 선생님 일정을 확인해 안내합니다.
인천에서 방문수업도 받을 수 있나요?
코딩 수업은 방문수업 없이 실시간 1:1 화상으로만 진행합니다. PC 또는 노트북, 안정적인 인터넷, 카메라·마이크가 필요하며 과정별로 설치할 프로그램과 방법은 상담에서 안내합니다.
수업료와 무료 체험수업은 어떻게 안내되나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 시간과 과정은 상담 후 정하며, 구성 변경에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업이 가능하며, 선생님 일정을 확인해 진행 방법을 안내합니다.
