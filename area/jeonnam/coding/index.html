처음 코딩을 배우는 경우

써 본 도구가 있는지 확인하고, 결과가 바로 보이는 짧은 코드를 직접 작성·실행하며 코딩 배우기를 시작합니다. 예제를 그대로 따라 쓴 뒤에는 값 하나를 바꿔 보는 연습을 함께 합니다.

학교 정보·프로그래밍 수업 보완

학교에서 쓰는 언어·도구와 교재·단원·평가 범위를 상담에서 확인하고, 학교 교재의 예제를 수업에서 직접 다시 작성하며 각 부분이 하는 일을 비교해 봅니다.

교재나 강의 예제와 내 코드가 달라 헷갈리는 경우

교재·강의의 예제와 수업이나 독학으로 쓴 코드가 달라 어느 쪽을 따라야 할지 헷갈린다면, 아래 순서로 두 코드를 비교하며 복습하는 연습부터 합니다.

학교마다 교육과정 편성과 사용하는 도구·언어가 다르므로, 실제 교재와 수업 자료를 확인해 안내합니다.

교재 예제와 수업에서 만든 코드가 다르면 어떻게 복습하나요?

짧은 답 두 코드의 표현이 다르더라도 먼저 해결하려는 기능이 같은지 확인합니다. 그다음 입력·처리·결과를 나눠 각 부분이 같은 일을 하는지 비교하고, 변수 이름처럼 바꿔도 되는 부분과 동작을 정하는 핵심 부분을 구분한 뒤 작은 예제를 직접 써 보며 정리합니다.

지역과 관계없이 쓰는 일반적인 학습 방법입니다. 교재나 강의의 코드가 틀렸다고 보는 것이 아니라, 같은 기능을 다르게 쓴 두 코드를 비교하는 연습입니다. 아래 예시는 「1부터 10까지의 합을 구하는 코드」가 교재와 수업에서 다르게 쓰인 가상의 상황입니다.

  1. 표현보다 해결하려는 기능이 같은지 확인

    직접 해 볼 것 두 코드가 각각 무엇을 하는지 한 문장씩 적고 비교합니다.

    예 교재 코드 — 1부터 10까지 더해 결과를 보여 줌 / 수업 코드 — 같은 범위를 더해 결과를 보여 줌. 1 + 2 + … + 10 = 55이므로 둘 다 55가 나와야 함

    확인 질문 두 코드는 같은 결과가 나와야 하는 코드인가요, 처음부터 다른 일을 하나요?

  2. 입력·처리·결과를 나눠 비교

    직접 해 볼 것 두 코드를 나란히 놓고 입력·처리·결과에 해당하는 부분에 같은 표시를 한 뒤, 차이가 어느 부분에 있는지 찾습니다.

    예 처리에서 교재는 횟수가 정해진 반복을, 수업 코드는 조건으로 멈추는 반복을 썼다면 처리 방식만 다르고 입력과 결과는 같음

    확인 질문 두 코드의 차이는 입력·처리·결과 가운데 어디에 있나요?

  3. 변수 이름과 핵심 동작 구분

    직접 해 볼 것 이름만 다른 부분과, 바꾸면 결과가 달라지는 부분을 나눠 표시합니다.

    예 합계를 담는 변수의 이름은 달라도 되지만, 합계를 0에서 시작하는 것과 10까지 포함해 더하는 범위는 같아야 결과가 55로 같음

    확인 질문 이름을 바꿔도 결과가 같은 부분과, 바꾸면 결과가 달라지는 부분은 각각 어디인가요?

  4. 현재 배우는 언어·버전에 맞는 설명 확인

    직접 해 볼 것 교재·강의와 수업에서 쓰는 언어와 버전이 같은지 확인하고, 처음 보는 문법은 지금 쓰는 환경 기준의 설명으로 다시 확인합니다.

    예 교재가 다른 언어나 이전 버전을 기준으로 쓰였다면 같은 기능을 쓰는 방법이 다를 수 있으므로, 수업에서 쓰는 언어·버전으로 설명을 다시 찾아보기

    확인 질문 교재와 수업에서 쓰는 언어·버전이 같은가요?

  5. 작은 예제로 직접 작성하고 질문 정리

    직접 해 볼 것 범위를 줄인 작은 예제를 두 방식으로 직접 써서 실행하고, 끝까지 이해되지 않은 차이는 줄을 짚어 질문으로 정리합니다.

    예 1부터 5까지로 줄이면 1 + 2 + 3 + 4 + 5 = 15이므로 두 방식 모두 15가 나오는지 확인하고, 「교재 코드에서 범위의 끝 값을 이렇게 쓴 이유」처럼 구체적인 줄을 짚어 질문하기

    확인 질문 다음 수업에 가져갈 질문은 어느 코드의 어느 줄에 대한 것인가요?

같은 기능을 하는 코드는 여러 방식으로 쓸 수 있습니다. 비교할 때는 「결과가 같아야 하는가 → 어느 부분이 다른가 → 그 차이가 결과를 바꾸는가」 순서로 확인하고, 교재와 강의 내용이 지금 배우는 언어·버전과 맞는지도 함께 봅니다.

전남 코딩과외 자주 묻는 질문

코딩을 처음 배우는데 시작할 수 있나요?
네. 써 본 도구가 있는지 먼저 확인하고, 화면에 결과가 바로 보이는 짧은 코드를 직접 작성·실행하며 코딩 기초부터 시작합니다. 교재 예제를 따라 쓰는 데서 그치지 않고 직접 바꿔 보는 연습을 함께 하며, 학교 수업을 보완하려면 사용하는 언어·도구와 교재·단원·평가 범위를 알려 주세요.
교재 예제와 수업에서 만든 코드가 다르면 어떻게 복습하나요?
표현보다 해결하려는 기능이 같은지 먼저 확인하고, 입력·처리·결과를 나눠 어느 부분이 다른지 비교합니다. 변수 이름처럼 바꿔도 되는 부분과 결과를 정하는 핵심 부분을 구분하고, 언어·버전이 같은지 확인한 뒤 작은 예제를 두 방식으로 직접 써 보며 질문을 정리합니다.
앱·게임 제작과 파이썬·자바 중 무엇부터 배우나요?
만들고 싶은 동작을 직접 만들어 보며 게임 만들기를 경험하고 싶다면 앱·게임 제작, 짧은 코드로 파이썬 기초를 익히려면 파이썬, 자바 문법과 실행 순서·오류 메시지부터 익히려면 자바 안내를 살펴보세요. 시작 과정은 사용해 본 도구와 배우려는 목적을 상담에서 확인해 정합니다.
전남에서 방문수업도 가능한가요?
코딩 수업은 방문수업 없이 화상으로만 진행합니다. 정해진 시간에 선생님과 실시간 1:1로 만나며, PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 필요합니다. 과정별로 필요한 프로그램과 설치 방법은 상담에서 안내합니다.
성인·직장인이나 독학 중인 사람도 상담할 수 있나요?
네. 성인·직장인은 코딩 경험과 배우려는 목표, 어려운 부분, 수업 가능한 요일·시간을 기준으로 상담합니다. 독학 중이라면 보고 있는 교재·강의와 직접 작성한 코드를 알려 주시면 두 코드를 함께 비교하며 이어서 배울 범위를 정합니다.
수업료와 무료 체험은 어떻게 확인하나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수업 구성은 상담 후 정하며, 구성에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업은 상담 신청 후 선생님 일정을 확인해 진행 방법을 안내합니다.
