FROM BLANK SCREEN

코딩 설명은 이해했는데 빈 화면에서 혼자 작성하기 어렵다면?

짧은 답 완성된 코드를 외우기보다, 만들 결과를 먼저 정하고 필요한 기능을 나누는 연습이 필요합니다. 가장 작은 동작 하나부터 작성해 실행하고, 예상과 비교하며 고친 뒤 참고 자료 없이 다시 써 봅니다.

지역과 관계없이 수업에서 쓰는 일반적인 학습 방법입니다. 아래 예시는 「두 숫자를 입력받아 합을 보여 주는 프로그램」을 설명용으로 든 것이며, 코드 대신 문장으로 나눠 보는 활동입니다.

  1. 만들어야 할 결과를 한 문장으로 적기

    직접 해 볼 것 프로그램이 끝났을 때 화면에 무엇이 보여야 하는지 한 문장으로 적습니다.

    예 「두 숫자를 입력하면 두 수의 합이 화면에 나온다」

    질문 결과 문장이 너무 길거나 여러 일이 섞여 있다면 어디서 나눠야 할지 물어봅니다.

  2. 입력·처리·출력과 필요한 기능 나누기

    직접 해 볼 것 결과 문장을 입력, 처리(계산), 출력(결과 표시)으로 나누고, 각각에 필요한 기능을 적습니다.

    예 입력: 숫자 두 개 받기 / 처리: 두 수 더하기 / 출력: 합 보여 주기

    질문 입력받은 값을 숫자로 바꿔야 하는지처럼 처음 보는 조건이 나오면 표시해 두고 질문합니다.

  3. 가장 작은 기능 하나부터 작성하기

    직접 해 볼 것 나눈 기능 가운데 가장 작은 것 하나만 골라 먼저 작성합니다. 한 번에 전체를 쓰지 않습니다.

    예 숫자 하나를 입력받아 그대로 다시 보여 주는 동작부터 작성

    질문 첫 줄이 떠오르지 않으면 어떤 기능의 어떤 부분에서 멈췄는지 말해 봅니다.

  4. 실행 결과를 예상과 비교하고 수정하기

    직접 해 볼 것 실행하기 전에 결과를 예상해 적고, 실행한 뒤 예상과 비교합니다. 다르면 한 곳만 고쳐 다시 실행합니다.

    예 3과 4를 넣으면 7이 나와야 한다고 먼저 적어 두기

    질문 오류 메시지가 나오거나 예상과 다른 결과가 나오면, 그 메시지와 결과를 그대로 보여 주며 질문합니다.

  5. 참고 자료를 덮고 핵심 부분을 다시 작성하기

    직접 해 볼 것 완성한 뒤 예제와 메모를 덮고 입력·계산·결과 표시 부분을 처음부터 다시 작성합니다.

    예 합 대신 두 수의 차를 보여 주도록 바꿔 다시 작성

    질문 다시 쓰다 막힌 곳은 복습 질문으로 적어 두고 다음 수업에서 확인합니다.

파이썬·자바 모두 같은 순서로 연습하며, 실제 연습 문제는 배우는 언어와 범위에 맞춰 정합니다.

FAQ

울산 코딩과외 자주 묻는 질문

코딩을 처음 배우는데 무엇부터 확인하나요?
사용해 본 도구와 직접 작성해 본 코드가 있는지부터 확인합니다. 처음이라면 출력·변수·조건·반복 같은 코딩 기초를 짧은 코드로 직접 작성하고 실행하며 시작하고, 학교 정보·프로그래밍 수업을 보완하려는 경우에는 사용하는 언어와 교재·단원·평가 범위를 상담에서 확인합니다.
설명은 이해해도 혼자 작성하기 어려우면 어떻게 배우나요?
완성된 코드를 외우기보다 만들 결과를 한 문장으로 적고, 입력·처리·출력과 필요한 기능을 나눈 뒤 가장 작은 기능부터 작성해 실행합니다. 실행 결과를 예상과 비교해 고치고, 마지막에는 참고 자료를 덮고 핵심 부분을 다시 작성해 봅니다. 막히는 단계는 수업 중에 바로 질문합니다.
앱·게임 제작과 파이썬·자바 중 무엇부터 시작하나요?
작은 기능과 동작을 직접 만들고 실행 결과를 확인하며 게임 만들기를 경험해 보고 싶다면 앱·게임 제작, 파이썬 기초 개념을 짧은 코드로 익히고 싶다면 파이썬, 기초 문법과 실행 순서·오류 확인부터 익히려면 자바 안내를 먼저 살펴보세요. 사용해 본 도구와 배우려는 목적을 상담에서 확인해 시작 과정을 정합니다.
울산에서 방문수업도 받을 수 있나요?
코딩 수업은 방문수업 없이 화상으로만 진행합니다. 정해진 시간에 선생님과 실시간 1:1로 만나며, PC 또는 노트북과 안정적인 인터넷, 카메라·마이크가 필요합니다. 과정별로 필요한 프로그램과 설치 방법은 상담에서 안내합니다.
성인·직장인이나 독학 중인 사람도 상담할 수 있나요?
네. 코딩 경험과 사용해 본 도구, 배우려는 목표와 어려운 부분, 수업 가능한 요일·시간을 알려 주시면 학습 범위를 정하고 선생님 일정을 확인해 안내합니다. 독학 중이라면 사용 중인 자료와 직접 작성한 코드, 막힌 부분의 오류나 결과를 함께 확인해 시작 범위를 상담합니다.
수업료와 무료 체험은 어떻게 확인하나요?
수업료는 주 2회·1회 60분·한 달 기준 월 300,000원입니다. 실제 수강 범위와 수업 구성은 상담 후 정하며, 구성에 따른 최종 비용은 상담에서 안내합니다. 무료 체험수업은 상담 신청 후 선생님 일정을 확인해 진행 방법을 안내합니다.
