KEY POINTS

단계별 중요 핵심

방문과외와 실시간 화상수업 모두 같은 원칙으로 수업을 설계하고 관리합니다.

  1. 학생별 맞춤 설계

    현재 수준과 목표를 확인하고 학생에게 맞는 수업 방향을 정합니다.

  2. 1:1 집중수업

    선생님과 학생이 1:1로 마주해 이해 속도에 맞춰 진행합니다.

  3. 과목·학년별 맞춤

    유아부터 고등까지 학년과 과목에 필요한 내용을 다룹니다.

  4. 학습상황 확인

    수업마다 이해도와 진도를 확인하며 부족한 부분을 짚습니다.

  5. 피드백과 학습관리

    수업 후 피드백으로 학습 방향을 점검하고 꾸준히 관리합니다.

학습 사례로 보는 수업 변화

영고2 · 영어오답 정리

영어에 자신이 없던 학생이 틀린 문제를 선생님과 하나씩 정리하면서, 문제를 푸는 방법을 조금씩 익혀 간 사례입니다.

수중3 · 수학풀이 순서 정리

수학 문제 앞에서 막막해하던 학생이 수업에서 풀이 순서를 정리하는 습관을 들이며, 시험 때의 긴장을 줄여 간 사례입니다.

습고1 · 학습 습관공부 습관 형성

혼자 공부할 때 무엇부터 해야 할지 몰랐던 학생이 매주 학습 계획을 함께 세우며 공부 습관을 만들어 간 사례입니다.

과고2 · 통합과학개념·유형 점검

모르는 개념과 문제 유형을 하나씩 짚어 가며 공부하면서, 스스로 할 수 있다는 자신감을 키워 간 사례입니다.

※ 위 내용은 학습 사례를 참고해 재구성한 예시이며, 학생·학부모가 직접 작성한 후기가 아닙니다. 학생마다 수업 과정과 결과는 다를 수 있습니다.

PROCESS

수업은 이렇게 진행됩니다

  1. 상담 신청

    학생의 학년·과목·목표를 확인합니다.

  2. 맞춤 수업 설계

    현재 수준과 목표에 맞춰 수업 방향을 정합니다.

  3. 선생님 매칭

    학생에게 맞는 전문 과외 선생님을 안내합니다.

  4. 무료 시범수업 및 피드백

    정식 수업에 앞서 무료 시범수업으로 수업 방향을 함께 점검합니다.

  5. 학습 시작

    학생에게 맞춘 1:1 수업을 시작합니다.
